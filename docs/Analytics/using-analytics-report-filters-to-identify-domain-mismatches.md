The Analytics dashboard offers the capability to identify misrepresented URLs. 

Dimensions are available in the Analytics dashboard reports that show the URL, Domain, and True Domain from which impressions are originating. This can also be configured as a scheduled report. 

![](https://lh6.googleusercontent.com/vaNE1Wg_40QJ8Rt-A8iq4_xirELBfNURH1s0EctIRYpaaon5UPSHENJ03qlXf6YFNq_FUGmqYaPQ2W5EeZhwK0TEcsjZ-Q9eoi7vCGKhsGSJPTUp0g5ZcLhCGB2DgS0S_HDaWu4L)

Note that these filters are available for default reports and only for some of our pre-set reports because pre-set reports are optimized for load speed and may not have all filters available. 

The relevant filters are the following:  

  * URL refers to the domain populated in the Pixalate measurement tags
  * Domain refers to the domain detected by Pixalate
  * True Domain is the actual domain the ad was served on regardless of the number of nested iFrames.
