Clients who use Amazon Ads are now able to implement Pixalate Blocking to filter IVT pre-bid directly in the platform, with a few simple clicks. You can enable Pixalate filtering on all Amazon owned-and-operated and third-party supply worldwide. 

This option is available on the “Line Item Settings” page within Version 3.1 of the line item resource for STANDARD_DISPLAY, AAP_MOBILE_APP, AMAZON_MOBILE_DISPLAY, and VIDEO line item types. Please see Release Notes [here](https://advertising.amazon.com/API/docs/en-us/info/release-notes#january-2022-release-notes) and Amazon’s reference documentation [here](https://advertising.amazon.com/API/docs/en-us/dsp-campaigns/#/LineItem).
