Ads.txt is a publicly accessible file which lists a website’s authorized digital ad sellers, aimed to increase transparency and prevent bad actors from spoofing a domain. To help media buyers ensure domains included in their media spend support ads.txt, Pixalate includes ads.txt compliance insights throughout its Media Rating Terminal (MRT) reporting. This page includes guidance on how to find this information.

* * *

#### Find Ads.txt compliance for a single domain

If you just want to look up the ads.txt compliance for a single domain, simply use the MRT’s lookup feature with the top search field or in the Insight report.

![](https://f.hubspotusercontent40.net/hubfs/2364596/0972f43a-9cf7-45e3-8ef7-f17800046faf-png.png)

When using the Insight report, be sure to select ‘Domain’ at the top first before looking up the domain, as when this is set to ‘Apps’, searching for a domain will not populate any results.

If a domain is ads.txt compliant, the domain’s Insight report will display and ads.txt tick box next to the domain name at the top of the page.

![](https://f.hubspotusercontent40.net/hubfs/2364596/20e73f09-6559-4ee7-ac49-9e83a99012b8-png.png)

![](https://f.hubspotusercontent40.net/hubfs/2364596/4f034941-be30-4671-979c-d798b140b5ad-png.png)

#### Find Ads.txt compliance in CVS import results

When importing your own list of domains, the results automatically display a column for ads.txt compliance.

![](https://f.hubspotusercontent40.net/hubfs/2364596/26420378-1a66-4744-a826-77c1d3cd22b0-png.png)

At this point, you have the option to use the report filters to narrow only show compliant (or uncompliant) domains.

![](https://f.hubspotusercontent40.net/hubfs/2364596/645bb6f1-d4ff-401d-96bd-1e8d76c574eb-png.png)

If you would rather this information be provided in a CSV file, be sure to include the Ads.txt field when selecting the ‘Download’ dropdown options.

![](https://f.hubspotusercontent40.net/hubfs/2364596/0bcea0e4-23c8-411c-82e9-bd482a804b8d-png.png)

#### Filter by Ads.txt compliance in the Discovery report

When building site lists within the Discovery report, an Ads.txt filter is available with the filter to ensure the domains viewed are ads.txt compliant.

![](https://f.hubspotusercontent40.net/hubfs/2364596/68ea5a51-cc1e-472c-932f-fbeee0ed585c-png.png)

A separate column is also available with in the report’s downloaded CSV.

![a65e891b-b7a5-490a-83e4-b312874d1548](https://f.hubspotusercontent40.net/hubfs/2364596/a65e891b-b7a5-490a-83e4-b312874d1548.png)
